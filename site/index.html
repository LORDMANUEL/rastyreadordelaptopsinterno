YUDE Asset Guard

Administración de activos corporativos.

Plataforma interna para inventario, telemetría, auditoría, enrolamiento y seguimiento operativo de equipos Windows y Android.

Repositorio Documentación CI / Builds

Backend

FastAPI + PostgreSQL + Alembic

RBAC, auditoría, identidad por dispositivo, enrolamientos temporales, historial de red y geolocalización aproximada por IP.

Windows

Agente Go x64

Servicio SCM, inventario de hardware, Wi-Fi, batería, BitLocker, TPM, antivirus, software instalado y heartbeat autenticado.

Android

Base MDM en validación productiva

Enrolamiento HTTPS, heartbeat, Device Owner base y trabajo periódico. El provisioning empresarial y firma release siguen en cierre.

Estado del proyecto

MVP técnico: funcional y validado por CI. Producción: en fase de hardening, firma de artefactos, Android Enterprise, backups/observabilidad y piloto físico.

El estado técnico detallado vive en docs/PROJECT_COMPLETION.md.
